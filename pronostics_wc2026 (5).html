CONFIGURATION

Cette app utilise Google Sheets comme base de données. Collez ici l'URL de votre Web App Apps Script.


📋 Guide d'installation rapide

  1. Crée un Google Sheet → Extensions → Apps Script
  2. Colle le contenu du fichier google_apps_script_WC2026.js
  3. Déployer → Nouveau déploiement → Application Web
  4. Accès : Tout le monde - copie l'URL
  5. Colle l'URL ci-dessus et teste la connexion
